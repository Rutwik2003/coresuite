# maintenance

Maintenance plugin state integration. Test server status notifications when maintenance changes.

**Master switch:** `modules.maintenance` in `config.yml`.

**Installed file:** `plugins/CoreSuite/modules/maintenance.yml`.

## Configure and enable

1. Back up your existing file.
2. Review the sections below, especially world locations, external services, costs and commands.
3. Install required integrations; do not assume console reward commands work without their target plugin.
4. Set the master toggle and restart in staging. Check `/coresuite modules` and the console.
5. Test ordinary-player access and persistence before production.

## Configuration sections

- `poll-seconds`
- `announce-changes`

## Setting reference

Only names and data types are published here. For defaults, units and detailed comments, inspect the configuration generated by your installed build. No live server values, credentials, locations or command payloads are included.

| Setting | Type | Guidance |
|---|---|---|
| poll-seconds | number | Set a numeric value; use the units and limits in your installed config. |
| announce-changes | boolean | Enable or disable this specific setting; the master module toggle still applies. |
