# Module directory

Every module below starts disabled in a fresh public preview. Follow the setup guides before enabling it. Setting tables document keys and data types only; server-specific values and configuration snapshots are deliberately excluded.

| Module | Purpose |
|---|---|
| [admin](admin.md) | Administrative server tools. Restrict access to trusted staff and test destructive operations on staging. |
| [announce](announce.md) | Server announcement presentation and delivery. Replace messages with your own branding. |
| [archaeology-rush](archaeology-rush.md) | Archaeology fragments, relic progression and curator rewards. Test completed brushing and repeat-use exploit prevention. |
| [auto-messenger](auto-messenger.md) | Scheduled chat announcements. Replace example links and choose a non-intrusive interval. |
| [bank-notes](bank-notes.md) | Money and experience withdrawal items. Test redemption, balance messages and item duplication resistance. |
| [chat-games](chat-games.md) | Timed chat challenges and rewards. Review answer handling, timing and payout commands. |
| [chat-mentions](chat-mentions.md) | Player mention formatting and feedback. Test alongside your chat formatter. |
| [clear-lag](clear-lag.md) | Scheduled entity cleanup. Review entity exclusions and warnings; this is not a universal lag fix. |
| [combat-tag](combat-tag.md) | Combat restrictions and tagging. Test death, disconnect and teleport behavior. |
| [creator](creator.md) | Creator codes and configurable perks. Review rank commands and expiry before granting access. |
| [custom-fishing](custom-fishing.md) | Custom catches, bags, upgrades, quests and tournaments. See the fishing guide for acceptance tests. |
| [discord](discord.md) | Discord bot and notification integration. Configure your own credentials, channels and privacy expectations. |
| [gambling](gambling.md) | Casino games and player wagers. Requires an economy; audit accounts can alter actual odds and must be reviewed transparently. |
| [grimoire](grimoire.md) | Experimental wand and spell progression. See the magic guide and test with fresh profiles. |
| [guide](guide.md) | Player guidance and configured guide rewards. Verify all commands and completion requirements. |
| [harvest-market](harvest-market.md) | Seasonal crop markets, mutations and farming rewards. Test payouts against your other shops to avoid loops. |
| [jump-pad](jump-pad.md) | Configured launch pads. Test landing safety, permissions and anti-cheat interactions. |
| [kill-podium](kill-podium.md) | Kill podium presentation. Review location/entity behavior before enabling. |
| [maintenance](maintenance.md) | Maintenance plugin state integration. Test server status notifications when maintenance changes. |
| [orders-board](orders-board.md) | Player resource orders and escrow-backed fulfillment. Test partial fills, cancellations and concurrent actions. |
| [playtime-rewards](playtime-rewards.md) | Playtime tracking and milestone rewards. Keep display text synchronized with actual payouts. |
| [profile](profile.md) | Player profile presentation. Verify dependencies and visible information. |
| [referral](referral.md) | Referral tracking and rewards. Test repeat claims and self-referral prevention. |
| [resource-pack](resource-pack.md) | Optional pack verification and delivery. Configure your own licensed compatible pack; see the pack guide. |
| [reward-codes](reward-codes.md) | Redeemable reward codes. Replace public example codes and review console commands. |
| [side-quests](side-quests.md) | Experimental quest objectives and progression alongside magic and encounters. |
| [store](store.md) | Configured store presentation and commands. Replace product/group names and review external links. |
| [vulcan-punish](vulcan-punish.md) | Configured anti-cheat punishment integration. Audit actions before enabling on players. |
| [website](website.md) | Server data/API integration. Configure a secret, restricted bind address and your own frontend. |
| [wishing-well](wishing-well.md) | Community contributions and configured prize draws. Test deposits, scheduling and payout persistence. |
| [world-bosses](world-bosses.md) | Four configurable boss encounters, rifts, contribution rewards and equipment shop. Replace example arena coordinates. |
| [world-encounters](world-encounters.md) | Experimental traveling encounters and scholars. Test spawn safety, trades and research progression. |
| [world-manager](world-manager.md) | World-related tools. Review locations and permissions before using on production worlds. |
