# chat-games

Timed chat challenges and rewards. Review answer handling, timing and payout commands.

**Master switch:** `modules.chat-games` in `config.yml`.

**Installed file:** `plugins/CoreSuite/modules/chat-games.yml`.

## Configure and enable

1. Back up your existing file.
2. Review the sections below, especially world locations, external services, costs and commands.
3. Install required integrations; do not assume console reward commands work without their target plugin.
4. Set the master toggle and restart in staging. Check `/coresuite modules` and the console.
5. Test ordinary-player access and persistence before production.
